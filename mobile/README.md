# Goal Horn for Android

The phone app runs on its own. It follows your team, shows the live score and the next game, keeps a list of your team's goals, and plays the horn through the phone's speaker or whatever it's connected to (Bluetooth speaker, soundbar, car). No computer needed.

It works like the desktop app: press the horn when you see the goal on TV, and each press teaches it how far your TV runs behind, so the scoreboard changes when your TV does. The automatic horn and the win horn are in Settings.

## Installing

Download `Goal-Horn-android.apk` from the latest `android-v` release on [GitHub](https://github.com/cwk01/goal-horn/releases) and open it on the phone. Android asks once to allow installs from your browser or file app; allow it, then tap **Install**.

## During a game

Leave Goal Horn open on screen. Android pauses apps in the background, so the score and the horn stop updating if you switch away or lock the phone. The app keeps the screen on from 30 minutes before the game until it ends (turn that off in Settings). Plugging the phone in is a good idea.

The horn plays even with the ringer on silent. It uses the media volume.

## Horn sounds

The app downloads your team's horn from `https://goalhorn.colbykordas.com/horns`, the same library the desktop app uses, and falls back to the built-in horn. **Settings > Horn sounds > Choose MP3** uses a file from the phone for that team instead.

## For developers

```
npm install
npm test             # tracker, delay learning and formatting with fake games
npm run typecheck
npx expo run:android # build and run on a connected phone or emulator (needs Android Studio)
```

The app uses native modules, so it runs in a development build, not Expo Go. `EXPO_PUBLIC_DEMO=next` or `EXPO_PUBLIC_DEMO=live` before `npx expo start` swaps in fake Bruins games for UI work.

Layout:

- `App.tsx`: first-run team picker and the main screen
- `src/leagues/`: one adapter per league, ported from the desktop app's `src/server/leagues/`, plus `last()` for the previous game's goals
- `src/tracker.ts`: polls the game, applies the TV delay, learns it from presses, sounds the automatic horns
- `src/library.ts`: horn library download and your own MP3s
- `src/teams.ts`: generated from `src/shared/teams.js`; regenerate it when teams change there
- `src/ui/`: horn button, game cards, goals list, settings
- `plugins/withReleaseSigning.js`: signs release builds with the upload key

`android/` is generated by `npx expo prebuild` and isn't committed. Change native settings in `app.json`.

Releases build on GitHub Actions (`.github/workflows/android.yml`) when you push a tag like `android-v1.0.0`. Bump `version` and `android.versionCode` in `app.json` first; Android won't install an update with the same or a lower `versionCode`. See the top of the workflow for the signing secrets.
